# Personal Landing Page - Walter Caballero

Este es mi sitio web personal y punto de contacto profesional. El proyecto está diseñado bajo un enfoque minimalista, priorizando el rendimiento y la legibilidad.

## 👤 Perfil Profesional
* **Desarrollador Web Fullstack**: Especializado en ecosistemas PHP (Laravel, WordPress), JavaScript (React, Node.js) y análisis de datos con Python.
* **Docente Investigador Universitario**: Enfocado en la investigación académica y la formación de nuevos profesionales en San Luis, Argentina.

## 🛠️ Stack Tecnológico
Este sitio utiliza las últimas versiones de herramientas de desarrollo frontend:
* **Vite 7**: El servidor de desarrollo y empaquetador más rápido de la actualidad.
* **Tailwind CSS v4.2.1**: Utilizando la nueva arquitectura nativa de CSS y el plugin `@tailwindcss/vite`.
* **Formspree**: Integración para gestión de formularios de contacto sin backend.

## 🚀 Despliegue
El sitio cuenta con un flujo de **Continuous Deployment**:
1. El código se aloja en **GitHub**.
2. Cada actualización (`push`) activa un build automático en **Vercel**.
3. El dominio está gestionado y protegido por la red de **Cloudflare**.
